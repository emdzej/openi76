# Playing

## In the browser

Open the [player](/play/), choose your disc images (disc 1's `.iso`, disc 2's `.iso` or `.bin`, and the
`.cue` next to the `.bin`, all together), and press **Import and play** or **Play without importing**.
The discs are told apart by their labels. Importing copies them into the site's private browser storage
(about 1.1 GB with disc 2's `.bin`), so later visits start at once. A recent Chrome, Edge, Firefox or
Safari works.

The toolbar under the game has the fullscreen switch, the sound, and the scaling filter (`sharp` keeps
the pixels even at any size). Holding <kbd>Esc</kbd> for a second stops the game.

## Controls

The mouse drives the shell's menus. In a mission the game reads the keyboard with the original's default
keys, from the game's `input.map`:

| Key | Action |
|---|---|
| Keypad <kbd>8</kbd> / <kbd>2</kbd> | Throttle / brake |
| Keypad <kbd>4</kbd> / <kbd>6</kbd> | Steer |
| <kbd>S</kbd> | Start the engine |
| <kbd>.</kbd> / <kbd>,</kbd> | Shift up / down |
| <kbd>Space</kbd>, left mouse button | Fire |
| <kbd>Enter</kbd>, right mouse button | Next weapon |
| <kbd>F1</kbd>-<kbd>F11</kbd> | The cameras |
| <kbd>Esc</kbd> | Skip a movie or a cutscene; the menu |

Change them in the Esc menu's Control Configuration; the keys are kept with the game's options.
